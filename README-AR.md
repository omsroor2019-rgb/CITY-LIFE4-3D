# CITY LIFE 3D — NOVA BAY ULTIMATE WORLD (V4)

مشروع لعبة قيادة وعالم مفتوح للأندرويد، بلغة C باستخدام raylib 5.5 وقالب `KarvinJ/raylib-mobile`. البناء يتم على GitHub Actions لإنتاج APK.

> **توضيح مستوى الرسومات:** هذه نسخة عالم مفتوح إجرائية بأسلوب Low-Poly محسّن، وليست رسومات فوتوغرافية أو بمستوى GTA V. المباني والسيارات والشخصيات والأشجار الحالية تُرسم بالكود باستخدام مجسمات raylib. لا تتضمن الحزمة نماذج FBX/GLTF احترافية أو خامات PBR أو تحريك شخصيات موشن كابتشر. أضيفت مساحة وأنظمة لعب أكثر، لكن الواقعية العالية تتطلب استبدال المجسمات الإجرائية بأصول ثلاثية الأبعاد مصممة خصيصاً.

## ما تمت إضافته في V4

### العالم والمدن
- مدينة NOVA BAY الأساسية بشبكة شوارع 16×16، ونحو 900 مبنى إجرائي متعدد الارتفاعات.
- مناطق المطار والميناء والحاويات والساحل والمركز التجاري والأحياء السكنية والصناعية.
- أرض أوسع وممر طريق يربط المدينة بمنطقة الهجولة الرملية.
- منطقة **DRIFT DESERT** مستقلة تقريباً بمساحة 420×500 وحدة عالمية، مع كثبان رملية وحلبة دائرية ومسار مزدوج وبوابة بداية/نهاية ومدرج متفرجين وأعمدة إنارة.
- خريطة مصغرة تعرض امتداد العالم ومنطقة الرمل.

### الحياة والحركة
- 96 شخصية NPC: شخصيات تتحرك في شوارع المدينة ومجموعة متفرجين ثابتين حول ساحة الهجولة.
- 60 مركبة مرور متحركة.
- 237 شجرة إجرائية تقريباً، بأنواع عريضة الأوراق وصنوبر ونخيل، موزعة في الأحياء والحدائق والممشى الساحلي.
- ثماني سيارات عرض متوقفة في منطقة تجمع الهجولة.

### السيارات والقيادة
- 12 شكلاً إجرائياً للسيارات: سيدان، رياضية، SUV، بيك أب، شرطة، فان، كلاسيكية، تاكسي، رالي، Muscle، كهربائية، وBuggy صحراوية.
- مرآب يتيح تدوير أشكال السيارات.
- قيادة، فرامل، نيترو، فرامل يد، انجراف، دخان وآثار إطارات.
- نقاط انجراف أعلى على الرمل، وغبار رملي بلون مختلف عن دخان الإطارات على الإسفلت.

### الموسيقى
- 6 مقطوعات إلكترونية أصلية مولدة خصيصاً لهذه النسخة ومضمنة بصيغة OGG.
- راديو يقرأ قائمة التشغيل `assets/music/playlist.txt` من ملفات الموسيقى المضمنة داخل APK.
- يدعم مسارات OGG وMP3 وWAV بحسب فك الترميز المتاح في raylib.
- يمكنك إضافة أغانيك إلى مجلد `assets/music` وإضافة سطر لها في قائمة التشغيل ثم إعادة بناء APK.
- لا توجد أغاني تجارية محمية بحقوق نشر مضمنة في المشروع.

## التحكم على الهاتف

- العصا اليسرى: المشي أو توجيه السيارة.
- ACTION: دخول السيارة أو الخروج منها أو التفاعل مع المهمة.
- GAS / BRAKE: التسارع والفرامل.
- HANDBRAKE: فرامل اليد والانجراف.
- NITRO: زيادة السرعة.
- NOVA FM: الانتقال إلى المسار التالي.
- زر المرآب: تغيير شكل السيارة.
- II: إيقاف مؤقت.

## التحكم عند الاختبار على الكمبيوتر

- WASD أو الأسهم: الحركة والتوجيه.
- E: التفاعل.
- Shift: بنزين.
- Space: فرامل أو قفز.
- Left Alt: فرامل اليد.
- N: نيترو.
- M: كتم الراديو.
- C: تغيير السيارة.
- Esc: إيقاف مؤقت.

## إضافة أغانيك

1. ضع ملف الأغنية داخل `assets/music/`، ويفضل OGG لتقليل حجم APK.
2. افتح `assets/music/playlist.txt` وأضف سطراً بهذا الشكل:

   `my-song.ogg|اسم الأغنية`

3. ارفع التعديل إلى مستودع GitHub وأعد تشغيل GitHub Actions.
4. سيضمّن البناء الجديد الأغنية داخل APK ويظهر اسمها ضمن دورة الراديو.

**مهم:** الراديو لا يفحص ملفات الهاتف تلقائياً. هو يقرأ الملفات المضمّنة في APK والموجودة في قائمة التشغيل. إضافة ملف إلى APK مثبت بواسطة MT Manager بعد البناء تتطلب تعديل ملف القائمة أيضاً ثم إعادة توقيع APK؛ الأسهل والأوثق إضافة الأغنية إلى مجلد المشروع وإعادة البناء.

## بناء APK عبر GitHub Actions

الملف `.github/workflows/android-apk.yml` يقوم بالخطوات التالية:
1. تنزيل مصدر اللعبة.
2. جلب قالب raymob.
3. تجهيز Java 17 وAndroid SDK وNDK وCMake.
4. نسخ `src/main.c` إلى مشروع Android.
5. نسخ `assets/` إلى `app/src/main/assets/` لكي تُضمّن الموسيقى مع APK.
6. تشغيل `:app:assembleDebug` ثم رفع APK كـ Artifact.

بعد رفع المشروع إلى الفرع `main` أو `master`، افتح تبويب **Actions**. عند نجاح التشغيل ستجد Artifact باسم:

`CITY-LIFE-3D-V4-ULTIMATE-WORLD-APK`

نزّله، فك ضغطه، ثم ثبّت APK على هاتف Android.

## حدود النسخة الحالية وما لم يكتمل

- لم تُضف بعد نماذج سيارات/شخصيات/مبانٍ احترافية خارجية؛ الموجود مجسمات إجرائية مبسطة.
- منطقة الهجولة رملية إجرائية وحلبتها وعناصرها مرسومة بالكود؛ ليست محاكاة رمال واقعية بفيزياء جسيمات كاملة.
- NPC الحالية شخصيات مبسطة ذات حركة مسارات أساسية، وليست ذكاءً اصطناعياً متقدماً أو حياة اجتماعية متكاملة.
- حركة المرور على مسارات أساسية، ولا يوجد حتى الآن نظام شرطة ومطاردات مكتمل.
- لا يوجد حالياً شراء منازل أو حفظ دائم للتقدم أو دخول داخلي للمباني.
- ملفات OGG المرفقة مقطوعات إلكترونية أصلية قصيرة قابلة للتكرار، وليست أغاني غنائية مسجلة.
- لم يتم بناء APK باستخدام Android NDK/Gradle داخل بيئة إعداد هذه الحزمة؛ نجاح البناء الفعلي يجب تأكيده بنتيجة GitHub Actions ثم الاختبار على هاتفك.
- الأداء يعتمد على الهاتف. إذا انخفضت الإطارات، يمكن تقليل مدى رسم المباني والأشجار وNPC والسيارات في مرحلة الضبط التالية.
